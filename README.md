# Nawin Asokan - Professional Portfolio

This repository contains my personal **professional portfolio**, built with **React, Tailwind CSS, and modern UI components**. It showcases my career journey, skills, projects, qualifications, and achievements in a simple, interactive, and responsive design.

---

## 🚀 Features

- **Hero Section** – A quick introduction and personal branding.
- **Career Summary** – Highlights of my professional background.
- **Experience** – Detailed work experience and roles.
- **Projects Showcase** – Selected projects with descriptions.
- **Skills & Qualifications** – Technical skills and certifications.
- **Resume Download** – Quick access to my updated CV.
- **Contact Section** – Easy way to reach me.
- **Modern UI Components** – Built using reusable components for scalability.
- **Responsive Design** – Works seamlessly on mobile, tablet, and desktop.

---

## 🛠️ Tech Stack

- **Frontend:** React (CRA), JavaScript (ES6+)
- **Styling:** Tailwind CSS, shadcn/ui components
- **Build Tool:** CRACO for configuration overrides
- **Package Management:** npm
- **Version Control:** Git & GitHub
- **Deployment Ready:** vercel

## 📦 Installation & Setup

Clone the repository:

```bash
git clone repo-professional_portfolio.git
cd nawinasokan-professional_portfolio/frontend
````

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```

Build for production:

```bash
npm run build
```

---

## 🐳 Run with Docker (Optional)

You can also run this project inside a Docker container.

### 1. Build Docker Image

```bash
docker build -t portfolio .
```

### 2. Run Container

```bash
docker run -d -p 3000:3000 --name portfolio_app portfolio
```

### 3. Restart Container (if needed)

```bash
docker restart portfolio_app
```

Now visit: **[http://localhost:3000]**
